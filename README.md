# Dandy's World for Windows
<img width="600" height="486" alt="image" src="https://github.com/user-attachments/assets/29e08226-7a5a-4736-8855-d4ecd0414ca6" />
Dandy's World for Windows is a Scratch project (https://scratch.mit.edu/projects/1190197135/fullscreen) that is converted into a .EXE file.

## Download Instructions
Download the Dandy's World Setup.exe file and run it. (Note, your antivirus might flag it, but still, run it.)
The prompts will create a Start Menu and AppData folder for Dandy's World.
